# 运行方式与现状

## 运行链路

当前运行时发现本地 QQ 进程并建立 Hook 会话，再由协议层处理数据、由 OneBot 层转换动作和事件。Core 负责账号级编排，WebUI 提供管理界面。各账号的会话、身份和消息数据分别管理。

因此，运行条件包含 QQ 客户端、对应平台的原生组件及匹配的运行环境。构建成功、离线测试通过或 API 返回成功，都不等同于真实 QQ 消息已送达或客户端已正确呈现。

## Docker

仓库工作流构建并检查 `linux/amd64` 镜像，但目前不推送到镜像仓库。可在仓库根目录自行构建：

```sh
docker build --platform linux/amd64 -t jiyu:local .
```

镜像不包含 QQ 客户端或图形环境；镜像构建成功并不表示 QQ 接入环境已经配置完成。

## 更新现状

霁羽的自有更新源尚未启用：应用内更新检查、下载和更新源探测目前不可用。若启动时发现当前安装目录或当前系统临时目录中存在历史待处理更新，程序会停止启动并保留现场。处理前请停止使用同一安装目录的其他进程，并检查相关历史临时目录、路径别名和事务记录；该检查不提供跨进程锁，也不覆盖所有历史临时目录。
