# 独立协议研究

霁羽正在研究减少对 QQ 客户端进程及 Hook 的依赖。`packages/protocol/src/direct` 是实验性协议组件，**不是可用的独立 QQ 登录模式**。

## 已有的工作

仓库中有部分协议编解码、响应处理和参考格式的扫码／注册组件；相关验证包含离线数据和本地回环测试。传输使用调用方提供的已连接 socket。研究记录区分目标静态证据、参考实现静态证据和合成测试，三者各自说明不同的问题。

## 当前边界

- 尚未建立经过验证的独立 QQ 会话，也未证明真实 QQ 登录与互通。
- QQ 签名、服务端身份验证、完整在线注册和心跳仍在研究或实现中。
- 实验模块尚未接入现有 OneBot / Bridge 运行链路；当前运行仍需要 QQ 和 Hook。
- 合成测试或本地回环通过，不证明服务端接受请求，也不证明消息送达。

具体观察、未解决问题和测试边界请查阅 [独立协议研发记录](https://github.com/JiyuHane/Jiyu/blob/dev/packages/protocol/DIRECT_PROTOCOL.md)。研究会持续变化，请以当前源码和记录为准。
